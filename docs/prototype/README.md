# Eddy prototype

Single-file, clickable prototype of Eddy, a keyboard-first multi-cluster UI for FluxCD.
Open `index.html` in a browser. All data is mocked (clusters prod-eu, staging, dev).

Try: `j`/`k` move, `l` open, `h` back, `⌘K` search, `r` sync, `R` sync with source,
`s` suspend, `L` logs, `a` Ask AI, `1`/`2`/`3` switch cluster, `?` all keys.

Ask AI only works when the page is opened as a Claude artifact; elsewhere it shows
"not available". See SPEC.md for the production design.
